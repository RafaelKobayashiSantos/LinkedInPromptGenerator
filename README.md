# LinkedInPromptGenerator

LinkedInPromptGenerator is a project designed to help users analyze job listings, compare opportunities, and make data-driven career decisions. It provides a structured way to evaluate position details, salary, benefits, and other key factors.

## Features

- Analyze job postings and extract relevant details
- Compare multiple job opportunities side by side
- Score positions based on customizable criteria
- Organize and store job data for future reference

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/RafaelKobayashiSantos/LinkedInPromptGenerator.git
   cd LinkedInPromptGenerator.git
   ```

2. Install dependencies (adjust based on your environment):

   ```bash
   pip install -r requirements.txt
   ```

## Usage

1. Open the project in your code editor.
2. Update any configuration or input files with your job data.
3. Run the main analyzer script:
    
   ```bash
   python main.py
   ```

4. Review the generated analysis results and reports.

## Project Structure

- `README.md` - Project documentation
- `main.py` - Entry point for running the analyzer
- `requirements.txt` - Project dependencies
- `data/` - Folder for job listings and output data
- `src/` - Implementation code
